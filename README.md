## 💻 Run Locally

### Prerequisites

- Node.js (v18 or later)
- Firebase Project
- Google Maps API Key
- Gemini API Key

### Installation

```bash
npm install
```

Create a `.env.local` file:

```env
VITE_GEMINI_API_KEY=your_gemini_api_key
VITE_GOOGLE_MAPS_API_KEY=your_google_maps_api_key
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
